# 流萤桌宠工作面板 v1.1.0

以角色 **流萤** 为核心形象的 Windows x64 非官方同人桌宠与快捷工作区。流萤可在桌面待机、响应点击、播放动作、表情、贴纸和语音；展开的工作区可管理快捷项目并使用独立动态壁纸。

## 本版重点

- 4K 视频壁纸改为 GPU 图形场景直接输出，降低逐帧 CPU 转换造成的卡顿。
- 工作区图标保持在动态壁纸上层。
- 新增统一设置窗口及 `0%–100%` 壁纸亮度调节。
- 创意工坊视频、网页和场景壁纸可通过独立原生窗口在工作区播放，不替换 Windows 桌面壁纸。
- 自动发现本机壁纸程序与创意工坊项目，并适配高 DPI 屏幕。
- 流萤待机动作“会萤的”增加 1 分钟独立冷却，降低重复语音频率。

## 下载与安装

1. 下载 `DeskPetPanel-v1.1.0-windows-x64.zip` 和对应的 `.sha256` 文件。
2. 使用 `.sha256` 文件校验下载内容后完整解压。
3. 双击 `Install-DeskPet.cmd` 安装；也可直接运行 `app\DeskPetPanel.exe`。

朋友电脑无需另装 Python。目标系统为 Windows 10/11 x64，建议使用支持 WebGL 2 的显卡和较新的显卡驱动。

## 校验值

Release 附件包含 `DeskPetPanel-v1.1.0-windows-x64.zip.sha256`，其中记录本次正式构建的 SHA-256。

## 默认设置

- 流萤 Live2D 模式
- 桌宠高度：180
- 音量：17%
- 随机互动间隔：3 分钟
- “会萤的”待机语音冷却：1 分钟
- 工作区项目和壁纸：空，由使用者在本机选择

## 使用提醒

- 保留完整 `app` 目录，EXE 依赖同目录的 `_internal` 与资源文件。
- 独立创意工坊壁纸功能需要目标电脑已安装并启动原生壁纸程序。
- 从桌面拖入的项目会设置隐藏属性；卸载前请使用“全部恢复到桌面”。
- EXE 当前未做代码签名，系统可能提示未知发布者，请核对 SHA-256。
- 配置与日志保存在 `%USERPROFILE%\.workspace_panel`。
- 流萤角色模型、图片、语音、音乐和 Live2D 运行组件分别适用其来源条款，详见仓库说明。

完整操作、源码构建、故障排查和素材说明见仓库 [`README.md`](../README.md)。
